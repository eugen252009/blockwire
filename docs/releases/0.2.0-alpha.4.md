# Blockwire 0.2.0-alpha.4 — Alpha

Local development candidate, **not published**. Python SDK: **0.2.0a7**.
Minecraft **26.3**, Java **25**, Fabric Loader **0.20.1+**, Fabric API required.

## New: standalone async controllers

Explicit trusted local Python `setup(bot)` / `loop(bot)` functions, normal
`asyncio.TaskGroup`, bounded events, immutable state snapshots and managed
cancellation. Walking plus conservative food use can share one input writer.
Other built-in skills remain exclusive. No MCP/model or embedded interpreter is
required. Start at [controller.md](../controller.md) and the source example.

The native delta is deliberately small: actor-fenced hotbar selection, shared
scene identity/capability observations, and independent lower-only per-key input
leases. Food/heartbeat renewal cannot restart a retained short walking lease.
Native physics, collision, consumption, combat, TLS, authentication, input bounds
and F8 remain in charge. Legacy request forms remain valid.

The Python package also retains the development fight policy/optimizations from
a4–a6. Their earlier combat/death evidence is historical, not fresh acceptance of
this candidate. The frozen alpha.3 artifacts are not overwritten.

## Retained features

- Bounded client-known observations and partial extended sight up to **64 blocks**.
- Optional **Mod Menu** settings, no auto-enable from opening the screen.
- Native player/menu/container actions and the existing flat-ground skills.
- Mandatory per-instance TLS trust/hostname verification/API key and F8 stop.
- No remote command/code/file RPC, teleportation, item spawning or custom physics.

## Qualification and limits

See [controller evidence](../evidence/controller.json). Deterministic async/native
contracts are **not real-Minecraft gameplay acceptance**. A subsequent
[installed-client smoke](../evidence/controller-live.json) qualified movement,
cancellation, short-lease retention, hotbar fencing and exclusivity in a
Creative/Peaceful fixture, then saved/quit. Empty inventory/full hunger blocked
the actual food-consumption trial; `already_full` is not an eating proof. Graphical walking while
eating, low-FPS/native consumption behavior, general survival and unattended use
remain **NOT RUN / unqualified**. The controller does not resume/join worlds or
respawn. Callbacks and deadlines depend on cooperative trusted Python; native
leases remain independent but cannot release during a stalled game thread/OS.

Stairs, jumps, general uneven terrain, swimming, shelter automation, automatic
save/exit/handoff and in-mod script launch are **NOT implemented**. Releasing keys
is not survival or a safe handoff. Supervise authorized isolated trials.
