# Blockwire 0.2.0-alpha.3 — Alpha

Local, unpublished candidate for Minecraft 26.3, Java 25 and Fabric Loader 0.20.1+.
Fabric API is required. Client-only: do not install on a dedicated server.

## Mod changes

- Bounded extended sight up to 64 blocks, visible-interactable discovery and compact
  sampled block surfaces. Loaded client data only; no hidden-container contents,
  chunk generation or increased interaction reach.
- Optional Mod Menu 21.x settings screen with English/German text, runtime enable/
  stop and separately saved startup preference. Mod Menu is not bundled/required.
- Typed bounded hostile observations and actor/target-guarded native attacks.
- Existing native movement, eating/use, inventory and menu controls remain available.

## Separate Python SDK/MCP 0.2.0a3

- Visible-target `approach`, bounded optional `autopilot`, progress/status/cancel
  and single-job actor ownership; no automatic activation or reconnect behavior.
- Forward-facing shared feedback motor: held W overlaps observations and small
  steering on known straight segments. Short native leases, stopped larger turns,
  target checkpoints and precise final positioning remain.
- Python wheel/sdist and the full allowlisted developer bundle are companion
  artifacts; the Modrinth JAR does not install or launch Python or a model.

## Compatibility and qualification

Keep existing settings, API credentials and instance TLS identity. Replace the old
JAR; do not install both. Legacy config/import/environment aliases and the existing
TLS service name remain unchanged. No trust downgrade or new remote code/file RPC.

Navigation remains loaded flat/full-block only. Damage avoidance is best effort
and currently forces crouching; threat-policy settings, automatic fight assessment,
mining goals and automatic shelter construction discussed during development are
NOT implemented by this release. Defense/evasion are separate explicit opt-ins.

Component tests and isolated regressions are documented in the repository. A
non-isolated operator smoke observed partial rolling travel, a danger-triggered
stop and a separately verified native sword transfer without further walking.
It does not qualify camera smoothness, combat or broad safety. Aiming overshoot
was reported. Isolated graphical testing of this exact alpha.3 artifact, full
Survival/two-client, combat/evasion and cross-platform qualification remain NOT RUN.

No account data, live configuration, certificates, private keys or saves are
included. This kit is local only: no upload, tag, push or publication performed.
